**腿二：被领跑者验证过的变体矩阵**——`checklist` / `check off` / `tracker` / `counter` / `visited map` / `interactive map` 这八套变体，加上 63 个国家公园 + 各州州立公园的页面池。

**预期能干到多少：**

基准线是领跑者的 **24,871/月、$782/月**。它只有 2.5 年、DR 0，而且这个赛道还没有一家做**游戏化**（成就 / 等级 / 挑战 / 连续打卡 / 进度可视化）——六个玩家清一色只做"记录"。

我的判断，分三档说：

- **保守（12 个月内）**：做到跟它一个量级，**2 万~5 万/月**。这个档位不需要新东西，把变体矩阵 + 州页铺满就能到，因为 DR 0 就能排第 1 这件事已经被验证了。
- **中性（18~24 个月）**：**8 万~15 万/月**。靠游戏化机制做出差异化、加上州立公园和 NPS 433 个单元的扩展面（领跑者已经做到 433 个单元，说明池子够大）。
- **乐观（2~3 年，做对了）**：**20 万~30 万/月**。前提是游戏化真的做出来、且能吃到 App 端的溢出流量——`national park passport app` 那条线（+56%）正是 App 化的入口。

**收入按 $782 / 2.5 万访问换算 → 每万月访问约 $314**：
- 5 万/月 → **约 $1,570/月**
- 15 万/月 → **约 $4,700/月**
- 30 万/月 → **约 $9,400/月**

**这个数字必须冷静看**：广告出价低得刺眼。`national park passport stamps` 顶部出价 $0.04~$0.79、`national park passport app` $0.05~$0.30。**纯 AdSense 变现的话，这个赛道的 RPM 会很低**，$782 的月收入就是明证。

**所以方案 A 的钱不在广告上，在联盟和电商**：`national park scratch off map`（880/月）、`national park journal`（390/月）、`national park bucket list`（390/月）全是 **100/100 广告竞争度**的电商词——卖家和 Etsy 在抢。你的位置是当那个"帮用户选"的页面，拿联盟佣金。这三类词的单价 $0.30~$1.91 也印证了商业价值。

## 四、结论：选方案 A，但把变现结构改掉

**三句话：**

1. **方案 A 的确定性远高于方案 B**：领跑的站 DR 0、域龄 2.5 年、还在 +192% 上涨，**证明这条线对新站开放**；而游戏站大盘的主力词集体 -12%~-67%，是逆风。\n2. **但方案 A 靠 AdSense 只能到 $782 那个量级（这是竞品已经做到的实测值）**，因为公园类词广告出价普遍 $0.04~$0.79。真正值钱的是那些 100/100 竞争度的电商词（scratch off map / journal / bucket list），**变现结构应该是"工具页吃流量 + 联盟带货收钱"**。\n3. **游戏化的位置是放大器，不是主题**。不要做"国家公园游戏"，要做"护照打卡工具，带游戏化机制"——前者所有词加起来不到 6,000/月，后者有 1.24 万/月的上升需求托底。

**最该抄的一手，是领跑者的页面矩阵**：同一个需求（打卡）拆成 checklist / check off / tracker / counter / visited map / interactive map 八套页面，每套一个词，全部打到第 1 名，同时用大词的 2~3 页位置捡剩余量（135,000 的 map 词排 25 位也能稳定收 98 的估算流量）。**这套结构不需要原创，照着复制到"州立公园 + NPS 433 个单元"上就是新地盘。**

## 五、这轮没做到的，说清楚

1. **`national parks game` / `national parks checklist` 这类词我没做难度精评**——上面所有搜索量都是规划师官方口径（体量），**不是哥飞版 KD（难度）**。要动工前得逐个跑一遍。

## 三、关于"适合 teenage 玩"，必须说清一件事

**搜索侧不存在"青少年玩国家公园游戏"这个需求。**

相关搜索里长出来的词是 `national park game online free`、`national parks quiz`、`national park word search`——后者（170/月）在 26-05 冲到 **480**，是**学校期末找活动素材的老师/家长**，不是青少年。青少年玩游戏不会搜"national park game for teens"，他们直接去 Poki / CrazyGames / unblocked games（库内快照：`unblocked games` 500 万/月、`crazy games` 500 万/月）。

真正对应孩子/家庭的是 `junior ranger`（**5,400/月**，是这批词里量最大的），但两个问题：① 它是 NPS 官方儿童勋章项目的词，用户要的是官方材料；② 26-03/04 因学校假期冲到 **14,800**，随后掉回 3,600，**-71%**，是脉冲词。

不过它的 **CPC $0.85~$3.77 是这轮所有词里最高的**——**家长在为孩子的公园活动花钱**这件事是确认的，变现价值真实存在，只是搜索量不稳。

## 四、真要做，三条路选一条

**方案 A（推荐）：游戏化打卡站——把护照做成游戏**
- 需求支撑：passport book 6,600 + passport stamps 2,400 + checklist 2,400 + app 1,000 ≈ **1.24 万/月**，四条线同步上涨
- 差异化切口：现有 6 家只做"记录"，你加**成就 / 等级 / 挑战 / 连续打卡 / 印章收集进度可视化**——把"集邮心理"做成游戏机制
- 你的想法在这里落地：不是"给青少年玩的游戏"，而是**"给收集型成年人和带娃家长玩的游戏"**（junior ranger 那条线的家长，CPC 最高）
- 变现：年票信息页（`america the beautiful pass` 9 万/月）+ 装备联盟 + 纪念品（`passport book` 本身是 3,600/月的电商词，竞争度 100/100）

**方案 B：小游戏站（吃 games 大盘），国家公园只当一个主题分类**
这是另一个赛道，不是国家公园赛道。哥飞在 5 群说过（2025-06-25）：**"小游戏站做到极致，就是 sudoku.com 这种的，游戏自己开发的，流量很大，最后被腾讯收购。"** 但 games 大盘的预筛难度普遍 43~100，你要有从零做游戏站的心理准备。

**方案 C：quiz / trivia 当内页**
`national park quiz` 320/月、`national park trivia` 1,000/月，量太小自己撑不起项目。但注意一个信号：**`national parks quiz` 的顶部出价 $21.73，而广告竞争度只有 1/100**——有机构在买这个词，商业价值不低，适合当方案 A 里的一个 H2 模块。
